# Who's Behind the Vote

A static, interactive taster of connected intelligence for personal insolvency, the PPSR and
restrained assets. It steps through three use cases on a synthetic graph, shows measured results for graph methods against a rules check, and explains where GraphAware
Hume fits.

**Live page:** https://simontemby.github.io/insolvency-graph-taster/

**Everything here is synthetic.** Every person, company, address, phone number, wallet and record
was generated. No real agency data was used.

This is an independent demonstration. It was not produced, reviewed or endorsed by the Australian
Financial Security Authority. Hume is GraphAware's intelligence analysis platform. Neo4j is a
trademark of Neo4j, Inc.

Pages: `index.html` (overview: the costs of complaint-led work), `complaint.html` (use case 1, a
complaint arrives), `debt-agreements.html` (use case 2, shared contact details on proposals),
`vote.html` (use case 3, future state), `priorities.html`, `why-graph.html`, `hume.html`,
`patterns.html` and `about.html` (method, assumptions, limits and every public source used).
`data.js` holds the pre-computed graph slices and test results. The pages load Cytoscape.js from
cdnjs and fonts from Google Fonts.
